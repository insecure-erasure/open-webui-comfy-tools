# TODO — Video Generation (WAN2.1 Flow)

## Goal

Extend the current tooling to support **video generation** through ComfyUI (e.g., using WAN2.1 or similar video pipelines). The LLM agent would be able to animate an image previously generated by `smart_generate_image` or generate a video from a prompt.

## Current status

✅ `generate_video.py` — tool created with the same structure as `enhance_image.py`:

- Same `comfyui_image_base_url` valve (UserValves > AdminValves > COMFYUI_BASE_URL)
- Accepts `prompt` (T2V) and optional `image_filename` (I2V)
- Calls ComfyUI API directly via httpx (POST `/prompt`, GET `/history/{id}`)
- Polls for completion with timeout (~10 min)
- Extracts video filename from the output node
- Returns `video_md:` with the HTML video block + `video_filename:`

## What remains

1. **Replace the placeholder workflow JSON** in `_VIDEO_WORKFLOW_JSON_RAW` with an actual ComfyUI export
2. **Update the node IDs** (`NODE_LOAD_IMAGE`, `NODE_GENERATE`, `NODE_OUTPUT`) to match
3. **Test** the tool end-to-end

## How it works

The approach mirrors the `comfyui_image_base_url` philosophy already used in `enhance_image.py`:

- The **same `comfyui_image_base_url` valve** (UserValves > AdminValves > COMFYUI_BASE_URL) controls the public base URL for video links.
- Instead of markdown (which can't render video in Open WebUI), the agent emits an **inline HTML block** that the frontend renders as a video player.
- The URL pattern follows the same convention as image URLs:
  ```
  {comfyui_image_base_url}/api/view?filename={video_filename}
  ```

## HTML block the agent emits

```html
<style>
* { margin:0; padding:0; box-sizing:border-box; }
body { background:#0d0d0d; display:flex; align-items:center; justify-content:center; min-height:100vh; }
</style>
<div style="background:#222">
  <video controls autoplay muted loop playsinline style="width:100%;display:block">
    <source src="{comfyui_image_base_url}/api/view?filename={video_filename}" type="video/mp4">
  </video>
</div>
```

## Tool return format

```
video_html: <full HTML block with player>
video_filename: <filename.mp4>

Paste the video_html value inside a code block in your response
(triple backticks) so the frontend renders it as a video player.
```

This follows the same structured key-value pattern as `smart_generate_image` (`image_md:`, `image_filename:`) and `enhance_image` (now also `image_md:`, `image_filename:`), making all tools chainable.
